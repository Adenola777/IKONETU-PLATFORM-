Add to the investor register

Paste the list, one investor to a line, with the register number, the name and the date they registered, in that order. A list copied from a spreadsheet or a table works, with its row numbers, headings and totals: lines that do not end with a date are left out.

For example: 001, Ada Okafor, 2026-07-01. Write each date as year, month and day.

What happens

  • Every entry is added, or none is, so a list is never half added.
  • An entry already in the register with the same name and date stays as it was, so adding a list twice changes nothing.
  • A register number already there with a different name or date stops the whole list, so nothing is overwritten.
  • The addition goes in the audit log with the register numbers it added.
